## Features

### 🌾 Farm
- **Auto Take Eggs**: Otomatis klaim telur dari incubator/nest eggs dan dust shop.
- **Auto Grab Scraps**: Otomatis mencari dan mengumpulkan scrap plate terdekat di arena/pit.
- **Auto Recycle Scrap**: Otomatis berjalan dan mendeposit scrap ke recycler pad jika kapasitas penuh.
- **Scrap Capacity Slider**: Atur kapasitas maksimal scrap plate yang dibawa (1 – 50, default: 20).
- **Auto Open Eggs**: Otomatis menetaskan telur secara berkala.

### 🏡 Plot
- **Auto Rebirth (Master)**: Otomatis memantau indikator Rebirth (`!`) dan mengeksekusi rebirth secara mulus sekaligus mengaktifkan modul pendukung secara otomatis.
- **[LOCK] Set Recycler Pad**: Kunci posisi Recycler Pad plot milikmu agar karakter berjalan ke titik yang tepat dan akurat.
- **Auto Buy Feeders**: Otomatis membeli feeder generator baru (Slot 1–8).
- **Auto Upgrade Feeder**: Otomatis meningkatkan level kecepatan feeder (Slot 1–6).
- **Auto Upgrade Recycler**: Otomatis upgrade level dan kecepatan mesin recycler.
- **Auto Upgrade Coop**: Otomatis memperluas kapasitas kandang (Expand Coop).

### ⚔️ Battle
- **Auto Start Tower**: Otomatis mengirim ayam masuk ke Frontier Tower secara berkala (dengan filter event lokal & jeda cooldown yang akurat).
- **Auto Arena**: Otomatis menekan 'Go to Battle' dan memulai pertarungan PvP/Arena.
- **Auto Close No Thanks**: Otomatis menutup popup hasil kekalahan/ronde ("No Thanks" / "Keep Climbing") agar loop lanjut tanpa macet.
- **Auto Close Popups**: Otomatis menutup pop-up notifikasi kas/saldo tidak cukup ("Not Enough Cash").
- **Send Chicken to Pit**: Tombol instan untuk mengirim ayam langsung ke Chaos Pit.

### 🛸 Events
- **Auto UFO**: Otomatis mendeteksi event UFO aktif dan mengirim ayam ke Pit/Chaos selama durasi event.
- **Auto Golden Goose**: *(Coming Soon)*
- **Auto Chicken Boss**: *(Coming Soon)*

### ℹ️ Info & Dashboard
- **Live Plate Grabbed Tracker**: Menampilkan jumlah scrap yang sedang dibawa secara real-time.
- **Live User & License Monitor**: Menampilkan status lisensi VIP Premium / sisa durasi Trial.
- **One-Click Discord Copy**: Tombol cepat untuk menyalin tautan komunitas Discord ke clipboard.

## Key System

Keyless / License System — Masukkan lisensi resmi atau nikmati Free Trial langsung di dalam loader.

## Usage

1. Buka Roblox dan masuk ke permainan **Grow a Chicken Fighter**.
2. Jalankan script hub menggunakan executor yang kamu gunakan.
3. Menu **ERDEVA HUB v2.6** akan muncul di layar.
4. Pilih tab menu yang diinginkan dan aktifkan fitur otomatisasinya.
